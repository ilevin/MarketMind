## v0.4.0 架构变更覆盖验证

### 核心重构组件

1. **个股同步执行器** (`test_stock_executor.py`, 4 项)
   - 三事务模式：创建 running 任务 → fetch/validate → 原子提交/回滚
   - 配置类错误立即终止（Token 缺失、UNKNOWN_INSTRUMENT、ALIAS_CONFLICT）
   - 空结果合法推进水位
   - Duration 毫秒级精确计量

2. **同步服务重写** (`test_history_sync_service.py`, 32 项)
   - 个股水位推进与单调不下降
   - 失败隔离（单股重试耗尽不阻塞其他股票，Run 状态=SUCCESS）
   - 自动补偿（失败股下轮从缺口继续）
   - 已追平股票零请求优化
   - 全部追平时 Run 状态=NOOP
   - 生命周期边界（list_date/delist_date 约束）
   - 系统级异常导致 Run FAILED，未提交股票水位不动

3. **个股有效区间计算** (`test_history_planner.py`, 10 项)
   - `stock_effective_range` 函数返回 `StockSyncRange`
   - 端点收敛到严格交易日历
   - 空区间检测（`is_empty` 属性）
   - 移除旧日级函数（pending_dates/lag_days/reconcile_watermark）

4. **今日统计多时区支持** (`test_history_today_status_counts.py`, 8 项)
   - UTC 服务器时区下北京时间跨日归属正确
   - `last_attempt_at` naive 直接 CAST 为 DATE（不触发时区转换）
   - `now() AT TIME ZONE 'Asia/Shanghai'` 获取当前北京日期
   - 同日先失败后成功只计成功

5. **别名服务个股口径** (`test_history_alias_service.py`, 7 项)
   - 旧代码股（000022.SZ）区间回填落规范码
   - ALIAS_CONFLICT 只失败该股不阻塞数据集
   - UNKNOWN_INSTRUMENT 拒绝不建占位证券

6. **管理 API 升级** (`test_admin_history_api.py`, 57 项)
   - Summary 个股口径统计（stock_count/up_to_date_count/lagging_count）
   - 今日成功/失败计数（today_success_count/today_failed_count）
   - `overall_status` 逻辑：RUNNING → ERROR(系统级) → LAGGING(个股缺口) → HEALTHY
   - 新增 `GET /api/admin/history-data/stocks`（分页/筛选/搜索）
   - 新增 `GET /api/admin/history-data/tasks/{task_id}`（任务详情）
   - Run 详情新统计列（processed/success/failed/skipped）

7. **前端个股页面** (`test_admin_data_page.py`, 21 项)
   - 数据集切换 chip 交互
   - 状态筛选下拉框（全部/成功/失败）
   - 搜索功能（名称/代码 LIKE）
   - 100 条分页控件
   - 失败行详情 modal（XSS 转义保护）

8. **中断恢复机制** (`test_history_sync_job_lifespan.py`, 3 项)
   - `recover_stale_runs` 批量中断 running sync_task
   - 水位不推进
   - 下轮按原水位重新同步
